# 지안 갤러리

원본은 OneDrive에 두고 `https://jian.jahab.workers.dev`에서 사진을 감상하는 별도 갤러리입니다. 모아의 기존 앱과 배포 파일을 수정하지 않습니다.

사용자는 **OneDrive 연결, 사진 2,354장 조회, 모바일 일반·시크릿 창에서 로그인 없는 접속, 영상 재생, 날짜 정렬**을 확인했습니다. HEIC 원본을 선택했을 때 미리보기만 유지되는 문제를 보고했으며, 최신 HEIC 변환 수정본은 아직 사용자의 Cloudflare에 적용되지 않았습니다.

기능: 사진·영상 목록, 촬영일·업로드일·앨범 순서 정렬, 사진/영상 필터, 일·주·월·년 기간별 묶음과 격자 크기 변경, 전체 화면 감상, 터치 스와이프, 방향키, 인접 사진 미리보기, 원본 확대, 슬라이드쇼, 영상 재생, 브라우저별 좋아한 순간과 이어 보기. 사진 업로드·수정·삭제 기능은 없습니다.

## 원본 다운로드가 시간이 지나 다시 실패하는 경우

운영 사이트에서 원본 경로가 HTTP 503과 “원본 링크를 갱신하지 못했습니다”를 반환하는 문제를 확인했습니다. 이전 코드는 개별 항목 조회가 원본 링크를 제공하지 않으면 45분 이내 목록의 링크만 재사용했고, 그 시간이 지나면 원본 조회를 중단했습니다. 최신 수정본은 정상 작동하는 앨범 목록을 다시 읽어 선택한 항목의 새 원본 링크를 얻습니다. HEIC 바이트 다운로드가 401/403/404/410으로 실패한 경우도 자동으로 갱신을 시도하며, 새 목록에서 제거된 항목과 갱신 중 변경된 소유자 연결은 차단합니다.

`dist/worker.mjs` 전체를 Cloudflare `jian` → Edit code에 붙여 넣고 Deploy한 뒤 갤러리를 새로고침합니다. 환경 변수 변경이나 OneDrive 재연결은 필요하지 않습니다. 갱신 직후 첫 원본은 목록을 확인하는 만큼 시간이 더 걸릴 수 있습니다. 수정본을 배포하기 전 임시 조치로 `/admin`의 **앨범 연결 확인·새로고침**을 실행하면 현재 저장된 링크를 새로 받을 수 있습니다.

추가 검증: 실패를 재현한 회귀 테스트를 포함해 37개 통과. 90분 지난 모의 앨범과 개별 조회 404 조건에서 자동 갱신 후 실제 공개 HEIC 샘플을 모바일 Chromium으로 1280×854 해상도 그대로 표시했습니다. 운영 사이트는 수동 Deploy 후 적용됩니다.

## 기간별 보기 적용

`dist/worker.mjs` 전체를 Cloudflare `jian` → Edit code에 붙여 넣고 Deploy한 뒤 갤러리를 새로고침합니다. 환경 변수 변경이나 관리자 앨범 새로고침은 필요하지 않습니다.

기존 격자 버튼을 **기간** 선택 메뉴로 바꿨습니다. **일**은 날짜별, **주**는 월요일부터 일요일까지, **월**은 달별, **년**은 연도별로 묶으며 한국 시간을 기준으로 합니다. 주 제목은 시작일과 종료일을 보여 줍니다. 일에서 년으로 갈수록 썸네일이 작아져 더 많은 항목을 한눈에 볼 수 있습니다. 선택은 브라우저에 저장됩니다. 촬영일·업로드일 정렬에 따라 해당 날짜로 묶고, **앨범 순서대로**에서는 원래 순서를 유지하며 기간 메뉴를 비활성화합니다. 기간 변경은 이미 불러온 목록을 다시 묶습니다. 다음 페이지가 화면에 들어오면 기존처럼 추가 항목을 가져와 같은 기간에 이어 붙입니다.

## 원본 화질·디자인 개선본 적용

1. `dist/worker.mjs` 전체를 Cloudflare `jian` → Edit code에 붙여 넣고 Deploy합니다.
2. 갤러리를 모바일 시크릿 창에서 새로 엽니다. 이 변경은 기존 저장된 앨범 목록을 그대로 사용합니다.
3. 사진을 선택하면 미리보기가 먼저 나오고 원본이 준비되는 대로 자동 교체됩니다. 일반 사진은 **원본 화질**, HEIC를 변환한 사진은 **원본 해상도 · HEIC 변환**을 확인합니다. 확대를 해제해도 높은 해상도를 유지합니다.

원본은 선택한 사진만 다운로드합니다. 이웃 사진은 작은 미리보기만 준비합니다. 빠르게 넘길 때 이전 다운로드·변환 작업을 취소하고 늦은 응답이 현재 사진을 덮어쓰지 않도록 처리합니다. 원본 용량과 통신 상태에 따라 다운로드는 오래 걸릴 수 있습니다. 원본 링크가 만료되면 한 번 갱신해 재시도합니다.

HEIC/HEIF는 해당 사진만 같은 사이트의 인증된 원본 경로로 내려받습니다. 브라우저가 바로 표시할 수 있으면 원본을 사용하고, 지원하지 않으면 기기의 별도 작업 스레드에서 JPEG로 변환합니다. 픽셀 크기를 줄이지 않으며 JPEG 인코딩 품질은 1로 지정합니다. JPEG 표시용 파일은 HEIC와 바이트·압축·색 표현이 동일하지 않으며 EXIF를 복제하지 않습니다. OneDrive 원본은 유지하며 **원본 열기**는 원래 파일을 제공합니다. 변환된 화면은 이 탭의 메모리에서 최근 3장·최대 24MB만 기억합니다. 큰 파일(32MB 초과), 5천만 픽셀 초과, 60초 준비 시간 초과, 지원하지 않는 기기에서는 미리보기를 유지하고 원본 열기를 안내합니다. 원본 다운로드 실패와 HEIC 변환 실패를 구분합니다.

변환기는 첫 HEIC 변환 때만 사이트에서 불러오므로 첫 목록에는 포함되지 않습니다. Cloudflare는 해당 파일의 전송을 중계하며 원본이나 변환 결과를 KV에 저장하지 않고, 이미지 변환은 기기가 수행합니다. 유료 이미지 서비스나 추가 비밀값 설정은 필요하지 않습니다. 배포 파일은 약 3.3MB, gzip 약 0.8MB이며 Workers 무료 플랜의 압축된 스크립트 크기 제한 안에 있습니다.

디자인은 사용자가 지정한 [80억 분의 1](https://1in8b.life/ko/)의 큰 명조체 제목, 와인색 강조, 얇은 테두리와 작은 모서리를 참고했습니다. 배경은 요청한 따뜻한 크림색 `#F6F1E7`입니다. 사진·영상 개수를 상단에 표시하고 화면 색상 전환을 제공합니다. 요청한 **작은 순간, 오래도록**, **우리의 순간을, 천천히.** 두 문구는 화면에서 제거했습니다.

제목용 Hahmlet 글꼴은 공개 글꼴을 작업 환경에서 부분 추출한 약 20KB 파일입니다. 빌드 파일에 글꼴과 SIL Open Font License를 함께 포함하므로 방문 시 외부 글꼴 서비스에 접속하지 않습니다. 사용자 지정 제목 중 포함되지 않은 글자는 시스템 명조체를 사용합니다. 원본 글꼴: [google/fonts의 Hahmlet](https://github.com/google/fonts/tree/main/ofl/hahmlet), 라이선스: `assets/Hahmlet-OFL.txt`.

## 기존 사용자의 개선본 적용

1. `dist/worker.mjs` 전체를 Cloudflare `jian` → Edit code에 붙여 넣고 Deploy합니다.
2. `/admin`에서 **앨범 연결 확인·새로고침**을 한 번 실행합니다. 이 단계에서 전체 목록을 읽고 기존 `GALLERY_KV`에 저장하므로 시간이 걸릴 수 있습니다.
3. **사진 N장 · 영상 M개. 빠른 조회용 목록을 저장했습니다.**가 나오면 일반 갤러리와 모바일 시크릿 창을 새로 엽니다.
4. 첫 60개, 스크롤 후 다음 60개, `촬영일 최신순`과 `업로드 최신순`, `영상만`과 재생을 확인합니다. 기존 Microsoft 앱과 Cloudflare 변수 설정을 사용합니다.

방문자는 저장된 목록을 읽으므로 매번 전체 앨범을 조회하지 않습니다. 화면도 처음부터 모든 항목을 생성하지 않습니다. 목록이 없으면 처음 요청에서 전체 앨범을 읽어 저장하므로 2단계에서 미리 준비하는 것이 좋습니다. 페이지별로 원본 접근 서명을 새로 발급하며, 이미 저장한 목록에 포함된 항목만 열 수 있습니다. 사진·영상 원본은 OneDrive에 남습니다.

날짜는 촬영 메타데이터 → 카메라 형식 파일명 → 원래 파일 생성일 → 업로드일 순으로 보완합니다. 촬영 메타데이터가 업로드일과 같고 카메라 파일명 날짜와 크게 다르면 파일명 날짜를 사용합니다. `20250909_083516466_iOS.jpg`와 `20250911_072640236_iOS.jpg`는 각각 한국 시간으로 2025년 9월 9일과 11일로 표시됩니다. 표시한 날짜의 출처를 감상 화면에 함께 보여 줍니다. 날짜 정보가 없는 항목은 양쪽 촬영일 정렬 모두 마지막에 둡니다.

영상은 목록에서 ▶ 표시와 길이를 보여 주고, 열었을 때 브라우저의 재생·탐색·소리·전체 화면 제어를 사용합니다. 목록 탐색 중 모든 영상 원본을 미리 내려받지 않습니다. 브라우저가 지원하지 않는 MOV/HEVC 등은 원본을 열어 확인해야 할 수 있으며 서버에서 영상을 변환하지 않습니다.

## 1. Cloudflare에 코드 올리기

1. [Cloudflare 대시보드](https://dash.cloudflare.com/) → Workers & Pages → `jian` → Edit code.
2. `dist/worker.mjs`의 내용을 **전부 복사해 기존 예제 코드 대신** 붙여 넣습니다. 이 파일에는 화면과 서버 코드가 모두 포함되어 있으며 외부 패키지는 필요하지 않습니다.
3. Deploy를 누릅니다. 아직 OneDrive 연결 전이므로 사진 대신 안내가 표시됩니다.

기본 앨범과 사이트 주소는 코드에 이미 반영되어 있습니다. 아래 서버 설정만 추가하면 됩니다.

## 2. KV 저장소 하나 연결하기

OneDrive 연결 정보와 빠른 조회용 사진·영상 목록을 저장합니다. 사진·영상 원본은 여기에 저장하지 않습니다.

1. Cloudflare → Storage & databases → KV → Create namespace. 이름을 `jian-gallery`로 정합니다.
2. Workers & Pages → `jian` → Overview → 오른쪽 Bindings → Add a binding → KV namespace.
3. Variable name에 **`GALLERY_KV`**, KV namespace에 방금 만든 **`jian-gallery`**를 선택하고 저장·배포합니다.

무료 Workers/KV 플랜을 유지합니다. R2, 유료 Images, 유료 플랜, 별도 도메인은 이 구성에 필요하지 않습니다.

## 3. Microsoft에 갤러리용 앱 등록하기

모아가 사용 중인 앱을 변경하지 않도록 **갤러리 전용 앱을 하나 추가**하는 방법을 권장합니다. 기존에 모아를 설정했던 Microsoft Entra 계정/디렉터리를 이용하면 됩니다.

1. [Microsoft Entra 관리 센터](https://entra.microsoft.com/) → 앱 등록(App registrations) → 새 등록(New registration).
2. 이름: `Jian Gallery`.
3. 지원 계정 유형: **개인 Microsoft 계정**이 포함된 항목을 선택합니다. 개인 계정만 선택할 수 있으면 그 항목을 사용해도 됩니다.
4. 리디렉션 URI의 플랫폼을 **Web(웹)**으로 선택하고, 다음 주소를 입력합니다. 모아와 달리 이번에는 SPA가 아닙니다.

   ```text
   https://jian.jahab.workers.dev/auth/callback
   ```

5. 등록 후 Overview의 **Application (client) ID / 애플리케이션(클라이언트) ID**를 복사합니다.
6. API permissions → Add a permission → Microsoft Graph → **Delegated permissions / 위임된 권한** → `Files.Read.All`을 추가합니다. 지속 연결을 위한 `offline_access`도 추가합니다. 코드가 연결할 때 이 두 권한을 요청합니다. 쓰기 권한이나 Application permissions는 필요하지 않습니다. 기본 `User.Read`는 이번 코드에서 사용하지 않습니다.
7. Certificates & secrets → Client secrets → New client secret. 만료 기간을 선택하고 생성합니다. **Value(값)**를 복사해 다음 Cloudflare 설정에 바로 입력합니다. Secret ID가 아닙니다. 이 비밀값은 채팅이나 저장소에 넣지 않습니다. 만료되기 전에 갱신하고 서버 설정도 바꿔야 연결을 유지할 수 있습니다.

`Files.Read.All` 위임 권한은 Microsoft 계정이 접근 가능한 파일을 읽는 권한입니다. Microsoft 승인 자체가 특정 앨범 한 개로 제한되는 것은 아닙니다. 서버는 설정된 앨범의 사진만 목록에 내보내고 그 사진에만 원본 접근 링크를 발급합니다. Microsoft 토큰과 앱 비밀값은 방문자에게 전달하지 않습니다.

## 4. Cloudflare 변수와 비밀값 입력하기

Workers & Pages → `jian` → Settings → Variables and Secrets → Add.

| 이름 | 종류 | 입력할 값 |
| --- | --- | --- |
| `PUBLIC_ORIGIN` | Text | `https://jian.jahab.workers.dev` (끝에 `/` 없이 입력) |
| `MS_CLIENT_ID` | Text | Microsoft의 Application (client) ID |
| `MS_CLIENT_SECRET` | Secret | Microsoft Client secret의 **Value** |
| `ADMIN_PASSWORD` | Secret | 직접 정한 긴 관리자 비밀번호. 20자 이상, 무작위 비밀번호 권장 |

Deploy로 적용합니다. 비밀값은 네가 대시보드에 직접 입력하면 됩니다. 나에게 비밀번호나 토큰을 보낼 필요가 없습니다.

선택 사항:

| 이름 | 종류 | 용도 |
| --- | --- | --- |
| `ALBUM_TITLE` | Text | 화면에 표시할 제목. 기본값 `지안의 순간들` |
| `ALBUM_ITEM_ID` | Text | 제공된 앨범 링크 리디렉션에서 확인한 ID가 기본값으로 들어 있음 |
| `ALBUM_SHARE_URL` | Text | 제공된 앨범 링크가 기본값으로 들어 있음 |

## 5. OneDrive 연결과 실제 앨범 확인

1. [관리자 화면](https://jian.jahab.workers.dev/admin)을 엽니다.
2. Cloudflare에 입력한 관리자 비밀번호로 로그인합니다.
3. **OneDrive 연결** → 해당 앨범을 소유한 Microsoft 계정으로 로그인하고 읽기 권한을 승인합니다.
4. 관리자 화면의 **앨범 연결 확인·새로고침**을 누릅니다. 사진·영상 개수와 목록 저장 완료가 표시되어야 성공입니다.
5. 일반 브라우저와 시크릿 창에서 [갤러리](https://jian.jahab.workers.dev/)를 각각 열어 방문자가 로그인 없이 볼 수 있는지 확인합니다. 휴대폰에서 스와이프·확대·다음 사진·원본 열기도 확인합니다.

앨범은 일반 폴더와 다르고 개인 OneDrive의 서비스 이전 상태에 따라 API 동작도 다를 수 있습니다. 사용자가 이 앨범의 사진 목록 조회는 확인했으며, 최신 개선본의 영상 수와 재생은 위 단계에서 확인해야 합니다. 400/403/404가 나오면 오류 번호만 알려주면 됩니다. 토큰, 관리자 쿠키, 비밀값은 필요하지 않습니다. 실패 시 임의로 드라이브 전체 사진을 공개하는 동작은 없습니다.

앨범이 API로 제공되지 않으면 사진 원본을 유지하면서 일반 OneDrive 폴더를 갤러리 대상으로 지정하는 방식으로 변경할 수 있습니다. 현재 코드는 그런 변경을 자동으로 하지 않습니다.

## 갱신·무료 운영

### 「OneDrive API 서버 연결 / TypeError」가 나오는 경우

초기 Graph 요청의 `redirect: 'error'`는 Workers 런타임에서 지원되지 않아 API 응답을 받기 전에 TypeError가 발생합니다. 최신 수정본은 `redirect: 'manual'`을 사용하며, 같은 `https://graph.microsoft.com/v1.0/` 경로로 이동하는 경우만 최대 3회 따라갑니다. 다른 서버로 인증 정보를 전달하지 않습니다. 최신 `dist/worker.mjs` 전체를 Edit code에 다시 붙여 넣고 Deploy한 뒤 관리자 화면에서 앨범 연결 확인을 실행하세요. 실제 앨범의 API 지원 여부는 이 오류 해결 후 별도로 확인해야 합니다.

### 앨범 확인에서 “잠시 연결에 문제가 있습니다”가 나오는 경우

최신 `dist/worker.mjs`는 로그인한 관리자에게만 안전한 실패 단계를 표시합니다. KV 읽기·쓰기, Microsoft 토큰 서버 연결·응답 해석, OneDrive API 연결·응답 해석, 사진·영상 목록 구성을 구분합니다. 외부 요청과 응답 읽기는 20초 제한을 두며, 원본 예외 메시지, Microsoft 응답 본문, 비밀값은 표시하지 않습니다. 관리자 오류 화면의 연결 상태는 확인되지 않은 것으로 표시하며, 그 문구만으로 연결 해제를 판단하지 않습니다.

먼저 Overview의 Bindings에서 `GALLERY_KV`가 KV namespace에 연결되었는지 확인합니다. 일반 Text/Secret 변수로 저장소 이름을 입력하면 작동하지 않습니다. 여전히 실패하면 최신 관리자 화면의 `[실패 단계: …]` 문구로 원인을 확인해야 합니다.

### 관리자 로그인에서 “요청을 확인할 수 없습니다”가 나오는 경우

초기 코드의 `Referrer-Policy: no-referrer`는 브라우저의 HTML 폼 POST에서 `Origin`을 `null`로 만들 수 있어 관리자 요청 검증과 충돌합니다. 현재 수정본은 `same-origin`을 사용합니다. 대시보드 Edit code에서 `'Referrer-Policy': 'no-referrer',`를 `'Referrer-Policy': 'same-origin',`로 변경해 Deploy한 뒤 `/admin`을 새로고침하세요. `PUBLIC_ORIGIN`도 Production에 `https://jian.jahab.workers.dev`로 설정되어 있어야 합니다. 출처 검사 자체를 제거하거나 `null`을 허용하지 않습니다.

- 목록은 KV에 지속 저장하고 방문자에게 60개씩 제공합니다. 방문 시 목록이 15분 이상 오래되었으면 기존 목록을 먼저 보내고 백그라운드 갱신을 시도합니다. 무료 Workers의 응답 후 실행 시간 제한 때문에 긴 앨범은 백그라운드 갱신이 완료되지 않을 수 있습니다. 확실하게 최신 목록을 반영하려면 관리자 새로고침을 사용하세요. KV의 지역 간 반영과 서버 목록 재확인에는 약 1분 지연이 있을 수 있습니다.
- 원본 접근 서명은 1시간 동안 유효합니다. 최근 15분 안에 저장한 OneDrive 원본 링크는 재생 시작에 재사용하고, 오래된 링크나 재시도·원본 열기는 해당 항목의 최신 링크를 조회합니다. 개별 항목 조회 API가 원본 링크를 제공하지 않는 앨범은 정상 작동하는 앨범 목록 조회로 링크를 자동 갱신합니다. 동시에 발생한 갱신은 합치고, 갱신된 목록은 이후 원본 요청에 재사용합니다. 브라우저 첫 페이지 목록은 같은 탭에서 5분 동안 임시 저장합니다.
- 좋아한 사진과 마지막 위치는 기기/브라우저마다 다릅니다.
- Cloudflare 연결 해제는 Microsoft 자체의 공유 링크를 제거하지 않습니다. 이미 방문자가 다운로드한 사진이나 캐시한 이미지, 이미 발급된 OneDrive 파일 링크는 회수할 수 없습니다.
- Workers Free: 하루 서버 요청 10만 건, 요청당 CPU 10ms. KV Free: 일일 읽기·쓰기 제한이 별도로 있습니다. 매우 큰 앨범이나 많은 동시 접속에서 무료 한도에 걸릴 수 있습니다. 사진 크기 조정과 원본 전송은 OneDrive가 맡습니다.
- 사진 원본은 OneDrive 용량을 사용하고 Cloudflare에는 원본 복사본을 보관하지 않습니다.
- URL을 받은 누구나 갤러리를 볼 수 있습니다. 검색 엔진에는 인덱싱하지 않도록 요청하지만, 링크를 받은 사람의 재전달을 막는 인증 기능은 없습니다.

## 개발·검증

```sh
cd gallery
npm test
npm run check
npm run build
```

검증한 항목: 서버·날짜·기간·배포 코드 테스트 37개, 2,354개 모의 사진의 KV 저장 후 Microsoft 호출 없는 첫 페이지 제공, 전체 목록 기준 정렬·필터·좋아한 항목·이어 보기, 영상 포함, 인증 정보 비노출, 앨범·연결 범위를 벗어난 원본 서명 차단, 리디렉션 정책, 관리자 CSRF, OAuth state. Cloudflare workerd 런타임과 모바일 Chromium에서 날짜·필터·스와이프·페이지 추가·H.264 영상 재생·닫을 때 재생 중지도 확인했습니다. 최신 UI는 400px 미리보기에서 2,400px 원본으로 자동 전환, 확대 해제 후 원본 유지, 느린 이전 원본의 덮어쓰기 차단, 원본 실패 시 미리보기 유지, 목록에서 원본 일괄 다운로드 방지, 글꼴 표시, 두 문구 제거, 밝은·어두운 화면과 320/390/1440px 레이아웃을 확인했습니다. 이 검증은 모의 파일을 사용하며 최신 원본 기능의 실제 다운로드 시간·무료 CPU 한도는 배포 후 확인해야 합니다.

Wrangler로 배포하려면 `wrangler.jsonc`에 실제 `GALLERY_KV` namespace ID를 선언하고 Cloudflare 인증과 Secrets를 설정해야 합니다. 현재 안내의 대시보드 붙여 넣기 방식은 Wrangler를 설치하지 않아도 됩니다.

공식 참고: [Workers Secrets](https://developers.cloudflare.com/workers/configuration/secrets/), [Workers KV](https://developers.cloudflare.com/kv/get-started/), [Microsoft 앱 등록](https://learn.microsoft.com/en-us/graph/auth-register-app-v2), [OneDrive 앨범 API](https://learn.microsoft.com/en-us/graph/api/bundle-get?view=graph-rest-1.0).

HEIC 추가 검증: 공개 libheif HEIC 샘플을 모바일 Chromium에서 1280×854 해상도 그대로 표시, 1회 원본 다운로드, 첫 목록에서 변환기 미로딩, 동일 탭 변환 이미지 재사용, 확대·닫기 취소를 확인했습니다. 사진 바이트 중계에서 인증 정보 비전달, 임의 리디렉션 차단, 연결 범위·크기 제한도 검증했습니다. 운영 앨범의 실제 HEIC 표시와 준비 시간은 수정본 배포 후 확인해야 합니다. 변환기 출처·라이선스는 `assets/vendor/README.md`에 기록했습니다.
